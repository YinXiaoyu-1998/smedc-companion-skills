# 美团套餐销售统计下载

## 确定本次范围

- 接受一个营业日或一段营业日、指定门店或明确的全门店范围，以及保存目录。相对日期按北京时间解析，续跑保留原范围。无法从请求或任务配置确定日期、门店时询问。默认保存到当前用户的 Downloads。
- 一份工作簿对应一个营业日，可以有多家门店。范围请求逐日设置相同的起止日、查询并导出，分别保存原件。跟踪每一天的查询、下载和验证结果，续跑时复用范围一致、已验证的文件。
- 保留美团原始 XLSX 字节。默认可保存为 `meituan_combo_sales_YYYYMMDD.xlsx`，日期用工作簿核验后的营业日。同日有不同门店范围时使用能区分范围的文件名或目录。同名文件先核对，另存有冲突的文件。
- 下载范围由用户请求决定。已获上传授权时，按当前 `smedc-mcp` 的套餐销售说明交付原件和验证后的营业日。数据集为 `combo_sales`，每份的 `startDate` 和 `endDate` 相同。用 `partitionImportJobId` 查到 `published` 才报告入库成功。

## 用 Computer Use 查询和导出

1. 如果环境提供覆盖此报表的专用导出工具，可优先使用。否则在 Codex 内置浏览器中复用美团标签或打开 `https://pos.meituan.com/web/operation/main#/`。用户指定本机浏览器，或内置浏览器确实缺少必需能力时，在指定或具备能力的本机浏览器操作。登录或验证码由用户在页面完成。
2. 进入 **报表中心 → 营业报表 → 套餐销售统计**。菜单不可用时，可尝试录制中观察到的 [套餐销售统计](https://pos.meituan.com/web/report/pack-sale#/rms-report/pack-sale)。确认标题、统计方式和营业日期控件，按当前可见控件操作。
3. **统计方式**选「套餐明细」。在「营业日期」的两个日期控件中选择同一个营业日，分别核对起止值。打开门店树，选用户要求的门店并核对实际勾选项；勾选「按门店统计」。在「更多筛选」中勾选「显示菜品规格」，取消「同名菜品合并统计」。菜品分类、菜品名称、订单分类、菜品下单来源均选「全部」，以取得可入库的完整门店日来源。
4. 每次修改日期或筛选后，点「查询」，等待结果刷新，复核当前条件后再点「导出」。只有当前查询明确无数据时才将该日标为无数据。表格当前页条数不能代表全量。页面若提示额外限制，保留已确认范围并报告该限制。
5. 点击「导出」前先按当前工具文档注册下载捕获。录制中此按钮直接打开 Chrome 的系统「保存」对话框；若当前界面直接下载，检查选定浏览器的下载结果和目标目录。出现原生保存框时，操作发起下载的浏览器自己的窗口，核对目录及文件名再保存。若实际页面转入「下载清单记录」，按本次套餐报表、营业日和申请时间定位任务，生成中适度等待，完成后先注册捕获，再点该行「下载」。只在页面或本地证据能确认没有进行中的导出、下载或待保存窗口后才重试。

## 验证本地工作簿

- 核对新文件确实存在、非空并且可以读出「单品关联套餐销售明细」。从工作簿标题下面的筛选说明解析「营业日期」，验证起止值都等于目标日。**美团默认文件名含导出时间。文件名与文件系统时间均不能证明营业日。** 多日汇总缺少逐行营业日，需要回到页面逐日重新导出。
- 核对筛选说明中的统计方式、按门店统计、显示菜品规格、同名合并和全部范围与查询一致。验证表头包含「门店」「套餐」「单品名称」「规格」「销售数量」「菜品收入(元)」等来源列。用结果中的实际门店排查范围外记录。「已选若干门店」仅是选择数量，已选门店可能没有明细行。
- 有 `openpyxl` 时可用本技能的 `scripts/verify_combo_sales.py` 进行只读核验。例如 `python3 scripts/verify_combo_sales.py /absolute/path/report.xlsx --date YYYY-MM-DD --store 门店原名`。`--store` 可重复，省略表示只做日期与格式校验。工具环境提供自带 Python 时可使用其 `openpyxl`。也可用等价的工作簿读取工具检查上述条件。
- 汇报实际工作簿营业日、已保存文件的绝对路径、明细行数和实际出现门店数。只有通过验证的日文件才算下载完成；验证失败时保留原文件和错误原因，回到当日查询重新核对。
