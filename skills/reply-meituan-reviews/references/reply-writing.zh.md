# 中文餐饮评价回复规则

本指南整理本技能已确认的文案要求，随技能独立安装即可使用，不是第三方 `review-responder` 技能的副本。已安装该技能时可结合其本地指导；无正文跳过、一般改善意愿和审阅后发布均以本技能为准。

## 语气与事实

- 默认中文、不署名，每个回复单元格仅放一段能直接发布的正文，不夹标题、分类、分析、引号或占位店主名。用户指定语言、风格和优先级时遵从。
- 像店主自然说话，具体回应顾客提及的菜品或体验。一般用2–3个短句；内容多时可适当增加，不以字数代替针对性。
- 好评可以轻松、俏皮、亲切，变化开头和表达，不逐行复制同一模板或硬推销。用户要求幽默时，可调侃食物、自己的小馆或用餐场景，不嘲笑顾客。
- 幽默不覆盖诚恳：差评、卫生或身体不适等内容以关切和歉意为先，玩笑须克制。不把严重不满变成调侃素材。
- 门店背景来自用户提供或同一门店的可靠资料；顾客说“串很嫩”可以回应其感受，但不能由此编出产地、采购时间、工艺或营养/健康功效。
- 不因评分高就忽略文字里的不满，也不因评价短或缺背景就断言是假评论。未核实的争议以“您提到的体验”回应，不把指责写成已查证事实。

## 按内容起草

| 情况 | 回复重点 |
| --- | --- |
| 具体好评 | 接住一个真实细节，适度感谢，自然欢迎再来 |
| 有好有坏 | 认可被肯定的细节，也正面回应不满，不用夸奖掩盖问题 |
| 具体差评 | 承认体验不足、诚恳道歉，加一般改善意愿与下次体验的期望 |
| 笼统但有内容的不满 | 简短回应失望，不要求顾客补充证据才能起草，不编造原因 |
| 涉及健康、食品安全或争议 | 谨慎关切，不确认未经核实的因果或责任，不作健康判断或赔偿承诺 |

空值、空白、系统“未填写”提示或仅评分/图片由主流程直接跳过，不走上述文案步骤。

## 改善意愿与承诺边界

差评和明显不满不能只说抱歉。回应具体体验后，加入概括性的改善方向和期望，例如“我们会继续优化整体服务质量，希望下次能让您吃得更舒心”或“我们会持续改善整体用餐体验，也希望下次这口西北味更合您的胃口”。用词随评价变化，不机械粘贴。

这是一般改善意愿，不是已经执行的事实或保证。不得写已经核查、整改、查过订单、培训或联系顾客；不得承诺具体菜品改味/加量/降价、换厨师、限时上菜、专人跟进、退款、补偿或保证不再发生。用户明确允许一般改善意愿，不等于授权具体经营动作。

## 虚构示例

以下只示范写法，不提供任何真实门店事实，执行时按本次评价与资料重新写。

**好评：“肉夹馍的饼很酥，朋友都说好吃。”**

肉夹馍这声“咔嚓”，算是把大家的胃口都叫醒啦！谢谢您和朋友喜欢这口酥脆，下回想吃时来坐坐，熟门熟路更自在。

**混合评价：“羊肉串好吃，但等菜太久。”**

羊肉串得了您的认可，上菜却没跟上这份好胃口，让您久等了，实在抱歉。吃顿饭不该像等连续剧更新，我们会继续优化整体服务，希望下次能让您吃得更舒心。

交付前逐条检查：回应了原评价的实际内容，没有编造卖点/事实或具体服务承诺；不满评价有诚恳回应与一般改善意愿；回复正文没有分析、私人信息或未批准的经营动作。
