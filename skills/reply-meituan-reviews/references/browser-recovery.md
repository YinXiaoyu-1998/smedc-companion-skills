# 浏览器遮罩与有界恢复

进入经营宝评价页遇到遮罩、点击无效或 `No node found at given location` 时读取。适用于 Codex iab 的已验证恢复路径；其他工具只使用其当前文档支持的等价能力，业务范围和发布授权仍以 [主技能](../SKILL.md) 为准。

## 先分清遮挡、视口与登录状态

- DOM/可访问性树能读到评价列表、门店和关闭控件，并不代表它们当前可点击。页面可能同时存在浏览器兼容提示、评价管理升级介绍和消息提醒；DOM 顺序不代表遮罩层次。点击无报错也可能没有关闭目标。
- 点击失败或画面未变化后，取一次新截图，结合当前 DOM 确认实际阻挡目标的弹层及其所属父文档/iframe。父页面弹层用父页面定位器；评价筛选用实时确认的 iframe 定位器。不要在 iframe 中寻找父页面的关闭 X。
- 对当前 DOM 中已确认的关闭控件只读检查 `getBoundingClientRect()`，并与当前视口及截图比较。矩形须与视口有交集，点击位置还须落在实际可见部分；`visible: true`、非零尺寸或唯一匹配不能证明这一点。关闭 X 可能是没有文字/角色的 div 或图标，使用实时观察到的属性，不能固化带构建哈希的类名。
- 已验证的失败样本：约 662px 宽的 iab 中，升级弹窗关闭 X 位于 x=695–715，DOM 报可见，点击报找不到节点；同页快照还列出“我已知晓”，须按截图区分实际阻挡的层。这是布局/层次问题，不能据此判为登录失效或网站整体不可用。这些坐标只解释症状，不用作后续点击坐标。

## 窄视口导致关闭控件不可达

仅在上述证据确认关闭控件超出视口时，调整视口使弹层完整可操作；不在每轮启动时无条件设置尺寸。一旦本轮扩大成功，就保持到本轮任务结束，避免每个弹窗或门店反复切换尺寸。

1. 从当前浏览器工具文档读取 `viewport` 能力，复用已有 iab 绑定；首次需要浏览器绑定时从清单取得其当前 ID，不硬编码编号。若本环境没有该能力，转主技能的浏览器回退，不猜方法。
2. iab 已验证可设为 `1280 × 900`。设置后重新截图/读取位置，等新布局实际生效后再定位关闭控件；不沿用调整前的索引、矩形或坐标。保留 viewport 句柄及本轮已扩大状态，供后续工具调用复用，不在切店、切渠道或再次遇到弹窗时重复设置/重置。
3. 按截图处理实际遮挡目标的上层提示，逐个点击当前确认的 X/关闭/“我已知晓”，每次检查画面变化。只关闭非约束性介绍和提醒，不点击“开始体验”、浏览器下载、报名或同意协议。
4. 截图确认阻挡弹层消失，再打开评价日期选择器等无业务写入的控件，确认出现对应界面后收起。仅 API 返回成功、焦点变化、DOM 仍可读或列表总数可读均不足以证明恢复。快照仍列出提示而画面已无提示时，不据此循环点击；以实际画面及后续控件的有效响应判断。
5. 关闭弹窗并确认可继续后，保持扩大后的视口继续本轮任务；重新读取门店、渠道和全部筛选，续用原任务日期与进度。直到整轮任务正常结束或异常退出时，才统一恢复本轮临时视口覆盖；转其他浏览器不另起一轮，清理仍在本轮结束时执行。本轮未设置覆盖就不调用 reset，保留调用方原有设置。

当前 Codex API 示例（`browser` 是已有 iab 绑定；先以本轮工具文档确认能力）：

```js
const viewport = await browser.capabilities.get('viewport');
// 先读取 viewport.documentation()；仅在证实控件超出视口时执行。
await viewport.set({ width: 1280, height: 900 });
```

重新观察布局，关闭实际遮挡目标的弹层并验证控件。保留该句柄和视口，跨工具调用继续本轮全部门店/渠道的采集、交付及本轮已授权的后续工作；不在这里紧接着 reset。将下列清理放在整轮任务的收尾路径，正常完成与异常退出都执行：

```js
// 仅在本轮确实设置过临时覆盖时，于整轮任务结束执行一次。
await viewport.reset();
```

## 其他故障及停止条件

- 旧可访问性索引失效：读当前状态后从本次 DOM 重新定位，不复用旧索引或固定坐标。布局问题先按上节恢复，重载不能解决固定宽度弹窗超出窄视口的问题。
- 如有独立的页面加载/陈旧状态证据，可重载一次；重载后重新观察所有弹层，不连续刷新。一次有证据的定位/视口恢复和至多一次必要重载后仍失败，就按主技能使用可访问的现有登录浏览器会话并说明原因；不可用则交付已有进度和未读范围。
- 不用 `force`、DOM 删除/改样式、脚本 `.click()`、事件注入、改 UA 或迁移 Cookie 绕过问题；evaluate 仅作只读定位检查。截图与位置检查不构成处理验证码、安全警告或法律协议的授权。
- 若中断前可能已发送回复、提交导出或写入数据，恢复后先核验该操作的实际结果，再从已保存的身份/进度继续，不因恢复浏览器而重发、重建任务或扩大范围。
