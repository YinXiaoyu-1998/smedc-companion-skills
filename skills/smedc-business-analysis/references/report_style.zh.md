# 经营报告 HTML 样式说明

本报告样式面向门店经营复盘场景。第一屏展示报告名称、用户指定的期间和有数据支持的经营规模。经营诊断按「结论、基线、门店、渠道、餐段、机会」组织；周报与月报保留通用的对比、趋势、档口和产品模块。

设计约束：

- HTML 必须自包含，样式、数据和轻量交互脚本均内嵌在单个文件中。
- 不加载网络脚本、字体、图片或样式表。
- 表格保留列标题、排序交互和可访问标签；筛选控件说明所选范围，门店比较限定在同规模组内。
- 缺少支持数据时隐藏对应图表、章节及导航，用简短业务语言说明遗漏。空报告保留指定期间和一条提示，不用零值或历史数据重新打开本期分析。
- 覆盖明细、来源文件、文档 ID、查询任务与错误代码只保留在运行证据中，不出现在 HTML 或普通交付说明中。
- 缺失月份或周保留原有时间位置；折线不能跨越缺失期间。未知指标显示为空或不展示，不能解释为零。
- 诊断结论必须来自当前查询事实；机会池明确标注假设与限制，不复用旧数据中的固定判断。
- 服务没有提供的信息不得用本地原表或推测补齐；没有事实支持的话题直接略过。需要解释实际报告范围时，只简短说明相关章节遗漏。
- 收入趋势在门店选择旁提供日/周/月时间单位。周报默认周（52 个完整七天窗口，按指定同比周对齐），月报默认月（12 个完整自然月，去年同月）；日视图为截至报告期末最近 365 天，对齐去年同月同日，2 月 29 日同期留空。月视图不包含未结束月份。各视图直接汇总每日原始收入，缺记录留空，已记录零收入显示零。
- 趋势绘图区支持任意高度的横向指针移动：最近日期显示竖向虚线、两条线的对应标记，右上方固定显示本期/同期日期及收入（元）；缺记录明确显示“暂无记录”。左右方向键、Home/End 可逐期查看。底部总览支持双端缩放、选区平移、空白截选及起止选择器；日快捷为 7/30/90 天，周为 2/5/16 周，月为 2/6 个月，另有全年。切换门店保留选区，切换时间单位重置为全年，并更新坐标、提示与快捷范围。旧持久化 bundle 未保存每日历史时仅保留原有时间单位。
- 月会报告只覆盖经营、趋势、渠道、餐段、档口与产品模块。
- 完成事实报告后，由智能体按 `business_advisory.zh.md` 直接面向餐饮老板撰写顾问反馈，核验后嵌入首部。先展示少量优先行动，其余内容可展开；讲清事实、判断、可能原因和行动验证方式。有经营价值的检查改写为建议，有必要时再补充其他可能或比较口径；不固定展示可信度评分、判断边界及数据缺失清单。
- 顾问反馈中的证据显示业务标签、期间和单位，技术引用只留在 `advisory.json`。内容按所写门店范围固定，不随图表筛选器切换；每项行动必须写清对象。缺证据不显示该建议模块。
