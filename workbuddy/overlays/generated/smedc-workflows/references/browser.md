# 浏览器选择与恢复

本规则用于三项工作流的准备检查和正式运行，先于业务技能执行。默认 bsk Agent Window；读取当前工具文档和清单，复用该浏览器中的正确美团入口或新开标签。

1. bsk Agent Window 返回 `Browser is not available: bsk Agent Window`、清单明确没有 bsk Agent Window，或完成业务技能的一次有界恢复后仍缺必要能力时，说明实际原因，立即检查本机 Chrome 的对应美团会话。此时继续复核 `meituan_erp` / `meituan_reviews`、下载和格式能力，不因 bsk Agent Window 自身不可用将整轮判失败。仅加载中、未登录或一次下载超时，沿用业务技能的有界恢复规则。
2. Chrome 可用时复用准确入口，重新核对来源账号、集团／品牌、完整门店名及 POI、日期和全部筛选；已有登录状态不能代替这些核对。Chrome 未登录则让用户在页面自行登录；无可操作的浏览器、设备锁定或确需验证码时，保存准确阻塞及待续范围。
3. 同一范围的查询、导出任务、下载等待和保存留在选定浏览器。换浏览器前先核对已发导出是否仍在生成、下载或待保存；保留原 runId、日期窗口、已完成范围、导出 ID 和重试计数，先接续已有任务，缺失时才发新导出。重连不触发上传、发信或发布重放。
4. 按各业务技能的下载事件、连续等待、文件验证及精确清理规则处理；Chrome 的原生保存框只在实际使用 Chrome 时适用。需要登录／工具不可用只阻塞相关来源阶段，仍继续其他已获授权且可验证的独立阶段。

只使用宿主实际提供的浏览器工具；不搬运 Cookie、不改 UA、不猜接口，不绕过安全警告。准备检查保存最终实际使用的浏览器及会话证据，`ready` 表示该来源当前可操作，不要求浏览器必须名为 bsk Agent Window。
